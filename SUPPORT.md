# Support and feedback

Start with [Getting started](docs/GETTING-STARTED.md),
[Troubleshooting](docs/TROUBLESHOOTING.md) and [FAQ](docs/FAQ.md).

For a reproducible problem, open **Issues → New issue → Bug report**.
Include the app version, Windows/browser version, reproduction steps and
expected/actual behaviour. An optional screenshot should contain no private data.

Use **Feature suggestion** for a concrete improvement and explain the task it
would help with. Suggestions are not commitments to implement or release a feature.

This repository is for binary releases, documentation and feedback. The
application's development source is not published. Do not submit credentials,
access tokens, personal circuit files or unrelated private information.

No guaranteed response time or individual support service is offered.
