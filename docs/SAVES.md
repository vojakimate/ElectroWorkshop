# Saving, opening and updating

## Automatic local saves

The workshop saves work per exercise in the current browser's local storage.
It does not upload circuit documents to a server or require an account.
English and Hungarian share that storage. Your own device labels are preserved.

Different browsers and browser profiles have separate storage. Private browsing
may discard it when the private session ends. Clearing site/browser data can
remove automatic saves. Export important circuits to JSON files.

## Export and import

Use **Save** to download a circuit JSON file. Keep it in a folder you control.
Use the document menu's open/import action to reopen it.

The Basic edition rejects files containing smart devices or floorplans. It
does not silently remove those features or rewrite the original file. Not every
file from another edition/version is guaranteed to be compatible; keep originals.

## Update the portable program

1. Export important circuits to JSON.
2. Close the old launcher.
3. Extract the new release into a separate folder.
4. Review its release notes and settings documentation. Transfer only supported
   personal INI settings; do not replace new application files with older files.
5. Start the new EXE and check your work; import JSON backups if needed.

With the same browser/profile and the same local address, local storage may
remain available across program folders. Exported JSON is still the reliable
portable backup. The separate local address used by this edition does not
overwrite the full/NAS edition's browser storage.

## Files to share in bug reports

Prefer a small newly created example that reproduces the problem. Inspect it
before posting: labels and other document data can contain information you
entered. Do not publish personal circuit files, credentials or unrelated data.
