# Release notes

## 1.0.1 — 2026-11-05

- English is the default for first use.
- Added an external `ElectroWorkshop.ini` settings file: default language,
  remembered language selection and automatic browser opening.
- Settings changes require restarting the launcher, not rebuilding the EXE.
- Includes English/Hungarian help and private/non-commercial education terms.
- Prepared as a portable Windows release with SHA256 checksums.

## 1.0.0 — local preview

Initial conventional-workshop Windows edition with English/Hungarian interfaces,
physical/schematic views, measuring tools, connection tracing and local saves.
